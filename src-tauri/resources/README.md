# Needle 2 Model Directory

Place the Needle 2 model weights file (`needle2.cact`, ~13.7 MB) in this directory:
`src-tauri/resources/needle2.cact`

To download:
```bash
hf download Cactus-Compute/needle2 needle2.cact --local-dir src-tauri/resources/
```

When bundled, Fishman automatically packages this directory as application resources for 100% offline, zero-network AI copilot inference.
