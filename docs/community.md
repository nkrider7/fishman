# Community

Fishman thrives when developers share bugs, ideas, scanners, and workflows.
This page explains how to participate.

## How to contribute

1. Read [CONTRIBUTING.md](../CONTRIBUTING.md)
2. Follow the [Code of Conduct](../CODE_OF_CONDUCT.md)
3. Find an issue or open a Discussion
4. Submit a focused pull request

Good first paths:

- Documentation fixes
- Scanner plugins for a framework you use
- Import/export format support
- UI polish and accessibility
- Tests around utils and codecs

## How to report bugs

Use the **Bug report** issue form:

https://github.com/nkrider7/fishman/issues/new/choose

Include OS, Fishman version, and reproduction steps. Search existing issues
first.

Security issues → [SECURITY.md](../SECURITY.md) (private advisory only).

## Feature requests

Use the **Feature request** form, or open a Discussion under **Ideas** for
larger proposals. Explain the problem before the solution.

## GitHub Discussions

Enable Discussions on the repository (Settings → General → Features) and create
categories such as:

| Category | Purpose |
|----------|---------|
| Announcements | Releases and project news (maintainers) |
| Q&A | Usage help |
| Ideas | Feature proposals |
| Show and tell | Themes, scanners, workflows |
| Development | Architecture and contributing |

Link: https://github.com/nkrider7/fishman/discussions

## Discord

## Communication norms

- Be respectful and assume good intent
- Prefer public threads over private DMs for project topics
- Keep criticism about ideas and code, not people
- Credit others’ work
